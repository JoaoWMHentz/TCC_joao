# humano

Malha animada de uma pessoa caminhando (`meshes/walk.dae`), usada pelos
`<actor>` gerados a partir de [config/mundos/](../../config/mundos/).

Origem: modelo "actor" de Mingfei, Gazebo Fuel
<https://fuel.gazebosim.org/1.0/Mingfei/models/actor>, licença
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Arquivo sem
modificações; copiado para o repositório para a simulação funcionar offline.
